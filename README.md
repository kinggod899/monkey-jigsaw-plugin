# 猴王通用拼图（穷举）

绝区零一条龙（ZenlessZoneZero-OneDragon）第三方插件。自动完成游戏内「拼图」小游戏。

## 功能

站在拼图界面后运行本插件，它会自动把散落的碎块拖回正确位置。

- 自动识别面板格数（3×3 / 4×4 / 5×5 / 6×6），支持 2K / 4K 屏幕
- 按穷举逐个试位置：拖对了游戏会锁定碎块，拖错了就是两块互换
- 一次拖动同时确认两个位置，拖动次数比单边记录少约三分之一
- 拖动没生效会把同一对重拖一次确认，不会误判

## 使用方式

1. 进入游戏里的拼图活动，停在拼图界面
2. 打开一条龙 → 应用列表 → 猴王通用拼图（穷举）→ 运行
3. 插件不进一条龙每日列表，需要手动运行

## 设置

运行卡片上的齿轮按钮打开设置。

| 设置项 | 默认 | 说明 |
|---|---|---|
| 动作延时倍率 | 0.5 | 可调范围 0.3~3.0。数值越大每个动作越慢；出现大量「这一对拖不通」时调大。强烈建议游戏保持高帧率运行，帧率低时拖动容易失效 |

## 原理

面板里亮的是还能拖的碎块，暗的是已经拼好的部分。亮块四边都有黑框，已拼好的部分和邻居
连成一片没有黑框 —— 插件只靠这个判据区分，不依赖模板和 OCR。

碎块该放哪里无法从画面推算（图案是手绘插画，缩放后接缝处颜色渐变被抹平，边缘信息不足），
所以走穷举：把一块拖到别的亮格挨个试，拖对了游戏立刻锁定它，拖错了就是两块互换。一次
拖动能同时确认两个位置，所以收敛比单纯穷举快。

耗时参考（按一轮拖动约 0.5 秒）：3×3 约 15 次，4×4 约 41 次，5×5 约 105 次，6×6 约 210 次。

## 已知限制

- 需要玩家自己走到拼图界面，插件不负责从大世界导航过去
- 拼完后不处理结算弹窗，也不自动切下一张
- 面板里若有一格看着是亮块、实际拖不动（四边黑框齐全的固定图案），插件会试 4~6 次后
  剔除它继续拼剩下的
